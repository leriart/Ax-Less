Use when a task needs current public information or a specific source.

- State the fact you need and the best primary source for it.
- Search with a focused query; use result titles/URLs to pick authoritative pages.
- Open the source with fetch_url and quote the relevant passage, date and URL instead of trusting a snippet.
- If a page fails, try a primary-source alternative before falling back to a summary.
- Distinguish source-backed facts from inference; note dates for time-sensitive claims.
